把文档变成干净的 Markdown

拖拽 PDF、Word、Excel、PPT、网页或截图进来。文字版直接解析，扫描件走 Apple Vision 中文 OCR。整个服务是一个 Rust 二进制，不需要 Python，也不上传任何文件。

选择文件

支持 pdf / docx / xlsx / pptx / html / csv / json / xml / txt / md 与 jpg / png / webp / bmp / tiff，可一次拖多个。
